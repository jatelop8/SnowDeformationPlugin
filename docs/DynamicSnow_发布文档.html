English Description (Nexus)

DynamicSnow — Dynamic Snow Deformation (Geometry)

True geometric snow deformation for Skyrim SE/AE: walking carves real trenches into the landscape mesh (Black Myth Wukong style), compatible with ENB and Community Shaders. Unlike decal-based footprints, every step physically displaces terrain vertices with dynamic normals.

Features: player boot trenches from Havok collider shapes · horse & animal footprints via skeleton nodes · arrow impacts · spell explosion craters with snow rings · dropped-item imprints · weapon drag marks · snow/sand/mud material detection · 300-600s time-based recovery (no hard deletion, crash-safe) · seamless cross-cell deformation · performance: ~2ms average frame cost.

Requirements: SKSE64, Address Library (matching your game version). Recommended: Smooth Terrain (iSubdivisions=3) for high-detail 129² grid.

Credits: CommonLibSSE-NG, SKSE, Community Shaders (Josef), NMN Dynamic Footprints (NearMidnightNow), Hexabit Footprints, NifTools/pynifly, Smooth Terrain.
